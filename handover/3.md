# Milestone 3 — the auditor, one read-only leaf

## What landed

`src/bridge/containers.ts` names the positions a leaf can return.

```ts
type Act =
  | { tag: "done"; correlationId: string }
  | { tag: "rationed"; correlationId: string; filled: Qty }
  | { tag: "refused"; reason: string };
type Read<T> = { tag: "read"; value: T };
```

`filled` has to be a non-negative integer to decode. `rationed` decodes and is not produced. It appears when a market exists, including a lottery loss with `filled: 0`.

`AuditorC` is `invariant` and `reconcile`. The auditor registry allows `books`, `reconcile`, `journal recent`, and `journal trace`. It contains no mutation. `src/bridge/auditor.ts` calls those reads and returns the two reports. `src/bridge/rig.ts` opens a world, a journal, and an intent log under one directory, on the shared id source and clock.

`leafLocal` is the plug against the vendored algebra. `answer` returns raw `unknown`. The decoder returns the position or null. Null throws `${label}/${tag}: reply did not validate`. There is no default and no coercion. The probe in `src/bridge/leaves_test.ts` covers `{ tag: "nope" }`, a `done` with no `correlationId`, and a valid `refused`.

`src/log/reconcile_test.ts` pins the join:

- An engine wage with no intent record does not alarm.
- An agent journal line with no intent record alarms `write-without-reason`.
- A matched loan is quiet. A refusal is blocked and is absent from the journal.
- An ok intent whose correlation never reached the journal alarms `reason-without-write`.
- An `error` with no journal line is neither an alarm nor a block.

Reads log as one intent line, status `ok`, correlation `null`, reason `"read"`, and they do not alarm. There is no tensor in this milestone. The month's auditor runs two asks, sequentially. See `handover/5.md`.

## Rulings

- Shape absent and shape refused stay distinct. A command the registry never listed is refused before `attempted`, and the command does not run. A shape that was asked and fails its gate returns `Act` `{ tag: "refused", reason }`, written to the intent log only, under the same `callId` as its `attempted` line. `requestLoan` is the worked example, in `handover/4.md`.
- Reconciliation alarms only on `source: "agent"`. Engine lines are excluded by construction.
- The decoder throws. It does not substitute a neighbouring tag.
