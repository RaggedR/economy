# Milestone 14 — --live

The model client sits behind the same decoder. The scheduler does not know which one it called. The scripted path is unchanged. On `monthSeed` the journal is still `pay` then `lendBank`.

## What landed

`src/model/wire.ts` is the only file that knows a wire format. It speaks OpenAI-compatible chat completions. `GET /v1/models` supplies the id: the first id in the catalogue, or `ECONOMY_MODEL` / `GROQ_MODEL` when that id is listed. An id that is not listed is an error. No model id is written in the file. `ECONOMY_BASE_URL` defaults to `https://api.groq.com/openai/v1` and is how the host changes. The key is `ECONOMY_API_KEY` or `GROQ_API_KEY`.

A 429 or a 5xx waits, up to eight attempts. `Retry-After` is a number of seconds or an HTTP date. Failing that, the body phrase `try again in Ns`, then `2 × attempt` seconds. Half a second is added. The cap is 120 seconds.

A live leaf is asked the shape the scheduler already built. The model replies `{"tag":"commit"}` or `{"tag":"refused","reason":"..."}`. `commit` runs that shape through the gate, so the correlation id is the harness's. `refused` is one intent line and no journal line. Any other reply, including a `done` with an invented id, fails the decoder. There is no default.

The auditor does not read the brain. `readBooks` does not either. A model does not author the books.

A tensor owes both replies, and both leaves share one world file. Live answers on one rig run in ask order, so the two saves do not interleave. A scripted answer returns before the next leaf starts, and it does not enter that chain.

`--live` uses `realIds` and `realClock` and writes `demo-out/live`. `verify.sh` does not diff that directory. Without a key it returns 1 and writes nothing. `deno task live` is the command. The scripted replay does not pass `--live`.
