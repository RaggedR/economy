\begin{abstract}
\noindent
The economy in \texttt{automation-shock.tex} and \texttt{prompt-so-far.md}
is a treasury-pole gold demo: typed agents act through a gated command
surface, and the thing that combines them is addition of T-accounts.
This document records the containers, the serialisable world, and the knobs.
Part~\ref{sec:decisions} records the rulings that closed the open list.
The functions inside the scripted leaves are left to the agent that
implements them.
\texttt{plan-so-far.md} is earlier. Where it still says one bank, one
education stock, withdrawable mine deposits, household fission, or debts
cancelled in both directions, it is not the spec typed here.
\end{abstract}

\section*{Vocabulary}
\addcontentsline{toc}{section}{Vocabulary}

A container is a pair $(P, R)$. $P$ is the set of shapes an agent can be
asked. For each shape $p$, $R(p)$ is the set of positions that count as an
answer. A program of that container has type $(p : P) \to R(p)$. A raw model
has type $\mathrm{String} \to \mathrm{String}$. The decoder is what makes the
second into the first. A reply that does not decode throws. It is never
rewritten into a legal-looking position.

A container morphism from $(P, R)$ to $(Q, T)$ is a delegate
$u : P \to Q$ and an amalgamation
$f : (p : P) \to T(u(p)) \to R(p)$. Control goes down through $u$. Data comes
back up through $f$.

The state object on a set $S$ is the container $\Delta S = S \triangleright (\lambda\,\_.\, S)$.
MacBeth's unfolding theorem says a morphism $\Delta S \otimes X \to Y$ is
exactly a forward map, which reads the state and returns an output shape, and
a backward map, which splits into a writeback of a new state and an ordinary
reply. In this economy there is one such worker. Its state is the world.
The agents are memoryless leaves that worker delegates to. Last year's job
listings, standing raw-material orders, sales, and balance sheets are fields
of the world, read back through the command surface. Copying them into an
agent would fork the books.

What is not that state: the working directory, the turn counter, token
budgets, and the parameters of Part~III. On a scripted run the intent log is
an append-only file beside the world. On a live run the harness transcript is
a second register, $\Delta(\mathrm{Transcript})$, stamped with real ids and
real times. It is not seeded. A seeded clock on a live run is a false audit.

The four combinators are not interchangeable. $\otimes$ asks every agent and
owes every reply. $\times$ asks every agent and owes one reply. A market
phase is a tensor: every poster and every buyer answers. It is not a product.
Sequential composition $\triangleleft$ does not distribute over the sum $+$,
and the TypeScript conditional types distribute it anyway.
\texttt{seqC(phase, sumC(food, welfare))} silently means
``decide, then ask''. The month is ordinary scheduler code, in the manner of
\texttt{stalin/branch.ts}, not a \texttt{seqC} over a sum.

A gate is a smart constructor. It returns $\mathrm{Ok}(e)$ or
$\mathrm{Refused}(r)$. A refusal is a position, not an exception. The reducer
applies an $\mathrm{Ok}$ effect and does not judge it again. An empty reason
never reaches the reducer. The harness records \texttt{attempted} before the
call, then the outcome, under one call id.

The registry is the allowlist of commands. An agent cannot name a command
that is absent from its registry. From inside the agent, a missing command, a
gate refusal, and a broken tool are the same position.

\section{The agents}
\label{sec:agents}

Six leaves answer shapes. The engine in \S\ref{sec:engine} is not a leaf.
It has no reason and no registry. Public hospitals, public universities,
private hospitals, private universities, supermarkets, nightclubs, and tech
companies are firms. A firm is a bundle of books and machines. It is not a
seventh agent. The government leaf operates the public firms. An entrepreneur
leaf operates the firm it owns. A mine is a parcel with an owner, not a firm
and not a career.

Every mutating shape carries \texttt{reason: string}. Read shapes do not.
The shared answer of a mutation is \texttt{Act}.

\begin{keep}
\begin{lstlisting}
type Act =
  | { tag: "done"; correlationId: string }
  | { tag: "rationed"; correlationId: string; filled: Qty }
  | { tag: "refused"; reason: string };

type Read<T> = { tag: "read"; value: T };
\end{lstlisting}
\end{keep}

\texttt{rationed} is a committed partial fill. A lottery loss with
\texttt{filled: 0} is still an outcome of a legal order. It is written to
both logs. \texttt{refused} is not committed. It appears only in the intent
log.

\subsection{Household}

Every living person is a household leaf, including entrepreneurs and mine
owners. The extra shapes of those roles are summands, present only while the
role holds. Losing the firm or the last mine removes the summand. That is a
change of fibre, the same device as \texttt{ExportChoice} in
\texttt{stalin/containers.ts}.

\begin{keep}
\begin{lstlisting}
type Objective =
  | "happiness" | "health" | "education"
  | "savings" | "investment";

type HouseholdC =
  | Fib<{ tag: "books" }, Read<PersonView>>
  | Fib<{ tag: "prices" }, Read<PriceList>>
  | Fib<{ tag: "listings" }, Read<Listing[]>>
  | Fib<{ tag: "disclosure"; issuer: Id }, Read<Disclosure>>
  | Fib<{ tag: "jobArchive" }, Read<JobListing[]>>
  | Fib<{ tag: "bidEducation"; career: Career; reason: string }, Act>
  | Fib<{ tag: "bidCure"; disease: Disease; reason: string }, Act>
  | Fib<{ tag: "buy"; good: Good; qty: Qty; seller?: Id;
        reason: string }, Act>
  | Fib<{ tag: "buyCure"; disease: Disease; provider: Id;
        reason: string }, Act>
  | Fib<{ tag: "keepJob"; reason: string }, Act>
  | Fib<{ tag: "applyJob"; listing: Id; reason: string }, Act>
  | Fib<{ tag: "applyRent"; house: Id; reason: string }, Act>
  | Fib<{ tag: "offerHouse"; house: Id; ask: Money;
        reason: string }, Act>
  | Fib<{ tag: "occupyOrLet"; house: Id;
        mode: "occupy" | "let"; reason: string }, Act>
  | Fib<{ tag: "postRent"; house: Id; rent: Money;
        reason: string }, Act>
  | Fib<{ tag: "tradeMine"; mine: Id; side: "buy" | "sell";
        qty: Qty; limit: Money; reason: string }, Act>
  | Fib<{ tag: "acceptDebt"; instrument: Id; reason: string }, Act>
  | Fib<{ tag: "tradeShare"; bank: BankId; side: "buy" | "sell";
        qty: Qty; limit: Money; reason: string }, Act>
  | Fib<{ tag: "depositMine"; mine: Id; bank: BankId;
        reason: string }, Act>
  | Fib<{ tag: "requestLoan"; bank: BankId; amount: Money;
        collateral: Id; reason: string }, Act>;
\end{lstlisting}
\end{keep}

\texttt{Good} is \texttt{staple}, \texttt{luxuryFood}, \texttt{nightclub},
\texttt{tuition}. Luxury food is the only one that raises the health stock.
\texttt{tuition} names a \texttt{Career}. A private cure is not a \texttt{Good}.
It is \texttt{buyCure}: ten units of one specialty, from a named hospital.
It removes that disease and adds nothing to the stock. There is no clinical
good and no free health grant. Names used as positions and not defined in
this section (\texttt{PersonView}, \texttt{PriceList}, \texttt{Rate},
\texttt{FlowRow}, and the rest) are projections of the world types in
Part~II. They are not a second chart.

\texttt{buy} may name a seller. If it does not, the engine fills from the
cheapest posted lots. A glut does not need loyalty. A seller who posts more
units than buyers ask is left with inventory, and next month's price falls.

\texttt{keepJob} and \texttt{applyJob} exist only on the job step of the
special day. Health does not remove either shape. An incumbent who wants the
post keeps it at the same salary while unhealthy, until the firm fires them.
\texttt{applyJob} exists only when the person's level in that career is at
least the listing's generation. Among non-incumbents the healthiest eligible
applicant is hired. A person at low health, including a hard zero, is hired
only when eligible applicants with higher health do not fill the slots.
Ties at one health are a seeded lottery. \texttt{offerHouse},
\texttt{occupyOrLet}, \texttt{postRent}, and \texttt{applyRent} exist only on
their special-day steps. \texttt{tradeMine} of a liened or deposited mine
cannot be written. \texttt{depositMine} cannot be written on a liened mine.
A lien blocks transfer, and a deposit is a transfer.

\texttt{acceptDebt} exists only when the sum of the person's deposits at the
two banks is at least the savings threshold. The lender reads \texttt{disclosure} and either
accepts or does not answer that instrument. Silence is not a shape. The
issuer ratchets the rate next month because the offer went unfilled.

Reproduction has no shape. The engine applies the gate after the month's
trades. A parent in the voluntary band reproduces according to the
probability for its \texttt{Objective} (Part~III). A parent past the
mandatory ceiling reproduces with probability one.

\subsection{Entrepreneur, and the tech summand}

\begin{keep}
\begin{lstlisting}
type FirmC =
  | Fib<{ tag: "postPrice"; firm: Id; good: Good; price: Money;
        qty: Qty; reason: string }, Act>
  | Fib<{ tag: "postCure"; firm: Id; disease: Disease;
        price: Money; qty: Qty; reason: string }, Act>
  | Fib<{ tag: "postJob"; firm: Id; career: Career;
        generation: number; salary: Money; slots: number;
        reason: string }, Act>
  | Fib<{ tag: "assign"; firm: Id; person: Id;
        specialty: Specialty | null; reason: string }, Act>
  | Fib<{ tag: "fire"; firm: Id; person: Id; reason: string }, Act>
  | Fib<{ tag: "orderMachine"; firm: Id; machine: MachineType;
        generation: number; qty: Qty; limit: Money;
        reason: string }, Act>
  | Fib<{ tag: "upgradeOwn"; firm: Id; machine: Id;
        mode: "fire" | "redeploy"; reason: string }, Act>
  | Fib<{ tag: "issueDebt"; firm: Id; principal: Money;
        installment: Money; months: number; reason: string }, Act>;

type TechC =
  | Fib<{ tag: "strategy"; firm: Id;
        mode: "stay" | "expand" | "upgrade";
        reason: string }, Act>
  | Fib<{ tag: "orderMaterial"; firm: Id; material: Material;
        qty: Qty; limit: Money; rollover: boolean;
        reason: string }, Act>;
\end{lstlisting}
\end{keep}

\texttt{postCure} passes the gate only for a firm of kind
\texttt{privateHospital}. A public hospital does not sell cures.
\texttt{assign} is how a generic teacher or doctor is pointed at a subject
or a specialty for the coming month. \texttt{Specialty} is the five diseases.
It is not a career. \texttt{upgradeOwn} exists only on the job step, and only
for a machine the firm already holds. \texttt{orderMachine} exists only on
that same step. \texttt{fire} exists in any month.

The tech summand is present only for a firm of kind \texttt{tech}.
\texttt{strategy} is the product choice. \texttt{stay} posts the current
generation at the current volume. \texttt{expand} is a plan to buy more
machines of that generation and list more engineer slots.
\texttt{upgrade} is a plan to list an engineer slot at the next level and to
offer the new generation. The plan does not itself mint a generation. A
generation enters the world when a built machine of that generation is
delivered.

\texttt{orderMaterial} with \texttt{rollover: true} writes a standing order
into the world. The engine resubmits it each month at a higher limit, up to
the recorded ceiling, until it fills or the ceiling binds.

An entrepreneur is the household container plus \texttt{FirmC} scoped to the
owned firm, plus \texttt{TechC} when the firm is a tech firm. One person owns
at most one firm.

\subsection{Mine owner}

A mine owner is a household with at least one undeposited parcel. The mine
shapes are:

\begin{keep}
\begin{lstlisting}
type MineC =
  | Fib<{ tag: "postMaterial"; mine: Id; price: Money;
        maxUnits: Qty; reason: string }, Act>
  | Fib<{ tag: "sellMine"; mine: Id; ask: Money;
        reason: string }, Act>;
\end{lstlisting}
\end{keep}

\texttt{maxUnits} cannot exceed remaining stock. Posting less than the stock
is withholding. It is legal. A deposited mine is operated by the bank leaf,
and these two shapes disappear for that parcel.

The indigenous are mine owners at month zero. They are not a container.

\subsection{Government}

\begin{keep}
\begin{lstlisting}
type GovernmentC =
  | Fib<{ tag: "books" }, Read<PublicBooks>>
  | Fib<{ tag: "setTeacherMix";
        assign: { person: Id; career: Career }[];
        reason: string }, Act>
  | Fib<{ tag: "setDoctorMix";
        assign: { person: Id; disease: Disease }[];
        reason: string }, Act>
  | FirmC;
\end{lstlisting}
\end{keep}

\texttt{FirmC} here is scoped to the public hospital and the public
university. The government leaf has no \texttt{requestLoan}. It does not own
collateral, and a bank loan is the secured channel. It borrows by
\texttt{issueDebt}, whose disclosure is tax revenue and the salary bill.
It has no shape that pays cash, transfers a house, or buys food for a
citizen.

Public output is not divided across the population. Citizens
\texttt{bidEducation} and \texttt{bidCure}. The engine serves homeless, then
renters, then owners, and lotteries inside a tier. A winner receives one full
level, or ten units of the matching specialty. A loser receives nothing.
The sentence in the government section of \texttt{automation-shock.tex} that
still says each citizen receives public production divided by population is
the earlier rule.

\subsection{Bank}

The bank leaf is memoryless. It does not forecast. It has no model of the
economy. The loan decision is not one of its shapes. \texttt{requestLoan}
is judged by the gate in \S\ref{sec:gates}.

\begin{keep}
\begin{lstlisting}
type BankC =
  | Fib<{ tag: "postLoanRate"; bank: BankId; rate: Rate;
        reason: string }, Act>
  | Fib<{ tag: "postMaterial"; bank: BankId; mine: Id;
        price: Money; maxUnits: Qty; reason: string }, Act>
  | Fib<{ tag: "sellCapital"; bank: BankId; mine: Id;
        ask: Money; reason: string }, Act>;
\end{lstlisting}
\end{keep}

\texttt{postMaterial} exists only for mines deposited at that bank.
\texttt{sellCapital} exists only for those mines. The gate allows it only
when that bank's equity is negative, or its loans exceed
\texttt{leverageMultiple} times its marked mine base.
The quantity sold is the mine. Mines are parcels, not slices.
Depositors do not withdraw. They sell shares with \texttt{tradeShare}.

\texttt{BankId} has two inhabitants, \texttt{"a"} and \texttt{"b"}. Each has
its own loan rate, ore book, shares, dividend, and ten-times ceiling.

\subsection{Auditor}

\begin{keep}
\begin{lstlisting}
type AuditorC =
  | Fib<{ tag: "invariant" }, Read<InvariantReport>>
  | Fib<{ tag: "reconcile" }, Read<ReconcileReport>>;
\end{lstlisting}
\end{keep}

The auditor reads. Its registry has no mutation. \texttt{InvariantReport}
is the trial of Part~II: each financial instrument sums to zero, and each
flow column of the month sums to zero. \texttt{ReconcileReport} joins the
journal to the intent log on the correlation id. An alarm is a committed
mutation with no recorded reason. A blocked entry is a refusal, visible only
in the intent log. This join is the amalgamation. Sub-balances sum. Debits
equal credits. Nothing in the economy is a semilattice of partial maps, and
nothing is a picture concatenated from two reports.

\texttt{lendBank} creates a deposit owed by the lending bank.
\texttt{repayBank} destroys that deposit and retires principal.
Interest paid to a bank is a \texttt{pay} that lowers the payer's deposit
and raises that bank's equity. It does not retire principal, and it does
shrink the stock of customer deposits until the dividend pays it back out.
A private loan moves an existing deposit. Writing one off removes the asset
and the liability together and moves no deposit.
Maintenance is a \texttt{pay} whose row is \texttt{maintenance}, from the
firm that holds the machine to the tech firm in \texttt{Machine.builder},
at the contractual price for that career and generation. It runs in the
opening. If the builder has folded, the charge that month is zero.

\subsection{The engine}
\label{sec:engine}

The engine is the writeback of the world worker. It runs between leaves,
never as a leaf.

\begin{itemize}
\item Contractual flows at the opening: wages, bank installments, private
      installments, tax collected on last month's fills, and maintenance
      paid to each machine's builder.
\item Disease draws. A new disease pins health at zero.
\item Mark to market. A margin call sells the borrower's liquid assets in
      order: the two deposits, larger balance first, then bank shares, then
      private debt, then undeposited mine land. Foreclosure runs only if
      that sale is short.
\item The public lottery, after the bids.
\item Market clearing: cheapest lots if the buyer named no seller, then a
      seeded lottery on a sell-out.
\item Starvation. If the food fill is zero, sell liquid assets below the
      posted price by the distress discount and try the food book again.
      Three consecutive months with a zero fill and nothing liquid left is
      \texttt{death}.
\item Fold, when a firm cannot meet the opening flows. The waterfall is
      wages, then tax, then the bank, then unsecured holders. A food reserve
      for the months until the next special day is kept out of the estate.
      Unmortgaged houses are not seized.
\item Birth gifts and death routing, after trade.
\item The dividend, on the special day, after shares have traded.
\item The invariant assertion, after every effect.
\end{itemize}

A fold at the opening cannot be prepaid by a loan issued later the same
month. Obligations, then borrowing, then investment. A same-month loan
that covered an opening shortfall would remove that squeeze, so the fold
stays in this phase.

\subsection{The month}

Sellers post before buyers. Food and rent settle before discretionary
purchases. Discretionary purchases are luxury food, the nightclub, tuition,
and private cures. On an ordinary month the scheduler is:

\begin{enumerate}
\item Engine: contracts, disease, margin calls.
\item Government: the two mixes, seeing current disease counts and the
      job archive.
\item Tensor of households: the two bids. Engine: the lottery.
\item Tensor of firms, mine owners, and banks: prices and quantities.
\item Tensor of households: \texttt{buy} of \texttt{staple}. Engine: clear,
      then the starvation rule.
\item Tensor of households: discretionary buys. Engine: clear.
\item Tensor of issuers and of households: debt, mine trades, share trades,
      \texttt{requestLoan}, \texttt{orderMaterial}. Engine: clear, then
      \texttt{draw} of any firm deposit that remains.
\item Engine: births and deaths. Auditor: invariant and reconcile.
\end{enumerate}

Firing is a shape in steps 2 and 7, and on the job step below. It is legal
in any month. Hiring is not.

On the special-day month the same list runs, with one insertion. After
staple food, and before discretionary buys, the special day runs in this
order. Share trades do not run again in step 7 of that month. Mine trades
and debt still do, so the dividend can be spent on them.

\begin{enumerate}
\item Bank shares. Buyers and sellers both answer.
\item Engine: the dividend to the holders of record just produced.
\item House sales. Winners are a seeded lottery, not a price auction.
\item Tensor of owners: \texttt{occupyOrLet}.
\item Job listings and machine orders, then \texttt{keepJob} and
      \texttt{applyJob}. The incumbent who wants the post keeps it.
      Other eligible applicants are taken in descending health, and a
      shortfall of healthier applicants is what lets a low-health applicant
      in. Incumbent salary does not change.
\item Rents are posted, tenants apply, the sitting tenant is first, and the
      rest are ranked by salary. The year is paid in full or not at all.
      Health pins at zero for anyone left undwelled.
\end{enumerate}

\subsection{Leaves behind the containers}

Each leaf is a \texttt{Runner}. The default runner is scripted and
deterministic. A \texttt{--live} flag swaps in a model client behind the
same decoder. The scheduler does not know which one it called. The scripted
household reads its \texttt{Objective} and the price list. The scripted
entrepreneur reads last month's unit sales, which are on the firm. The
scripted bank reads the other posted rate, whether last month's loan book
was full, and its own loss line. None of them reads a forecast of the price
level.

The formulas inside those leaves are not fixed here. The agent that
implements a leaf chooses them. Part~\ref{sec:decisions} lists the slots.

\section{The world}
\label{sec:world}

The world is one JSON document. Money is an integer number of minor units.
Quantities of goods, ore, doctor-time, and teacher-time are integers.
A price is money per unit, an integer. A repayment whose installment does
not divide is not a value of \texttt{issueDebt}. The existing
\texttt{absfc\_core.py} is the invariant on a coarser chart
(\texttt{deposits}, \texttt{loans}, \texttt{bonds}, as floats). It is the
prototype of \texttt{check}. It is not this chart, and a float sum is not
the replay.

Ids and the month counter are fields of the world on a scripted run.
A live run uses \texttt{realIds} and \texttt{realClock} in the logs and
does not claim byte-identical replay.

  | "d0" | "d1" | "d2" | "d3" | "d4";

type FirmKind =
  | "supermarket" | "luxury" | "nightclub"
  | "privateHospital" | "privateUniversity"
  | "publicHospital" | "publicUniversity"
  | "tech";

type Objective =
  | "happiness" | "health" | "education"
  | "savings" | "investment";
\end{lstlisting}
\end{keep}

Level $n$ in a career is what lets a person operate a machine of that career
at generation $n$. An advanced engineer is an engineer at level at least 1.
The class is empty at month zero because every engineer starts at level 0.
Switching careers sets the new career's level to 0 and leaves the old level
in the record. It does not transfer.

\subsection{People and firms}

\begin{keep}

};

  kind: FirmKind;

\end{lstlisting}
\end{keep}

Health and happiness decay by the factors in Part~III, then rise by fills.
Health is then cut by the ceiling $H_{\max}(\mathrm{happiness})$. While
\texttt{diseases} is non-empty, or \texttt{dwelling} is null outside the
special day, health is zero and a luxury fill does not change it.
Luxury food is the only fill that raises health. Staple food does not.
It is the only good that resets \texttt{starvation}. A cure removes one
entry from \texttt{diseases} and adds nothing to the stock. Nothing in the
opening, and no public grant, adds to health. The stock does not trend up
on its own.

Capacity of a firm in a career is
\[
\sum_{\text{machines of that career}}
  \mathrm{output}(\mathrm{gen})
  \cdot \min\!\left(1,\ 
    \frac{\text{operators on hand}}{\mathrm{ops}(\mathrm{gen})}\right).
\]
Bureaucrats are the operators of admin machines. The ratio $\beta$ is that
requirement at generation 0, calibrated to 1. It is not a second formula.
A firm short of bureaucrats runs the productive machines it can staff, and
no further.

Two purses: a firm's deposits and a person's deposits. Each purse is split
across the two banks. Opening obligations are paid from the firm purse.
\texttt{draw} moves what remains to the owner after the capital step.
The household buys food from its own purse. Cash left inside the firm is
not food. There is no \texttt{timePreference} field. Career choice reads
the job archive. The five objectives already separate a patient agent from
an impatient one.

\subsection{Houses and mines}

\begin{keep}
\begin{lstlisting}
type House = {
  id: Id;
  units: number;           // positive multiple of 10
  owner: Id;
  occupant: Id | null;     // owner, tenant, or empty
  lien: Id | null;         // a bank loan id
};

type Mine = {
  id: Id;
  material: Material;
  stock: Qty;
  owner: Id;               // a person, or a bank id once deposited
  depositedAt: BankId | null;
  lien: Id | null;
};
\end{lstlisting}
\end{keep}

A house trades only on the special day. A mine trades any month, unless
deposited or liened. Depositing mints shares and sets \texttt{owner} to the
bank. The parcel does not come back. Extraction subtracts from
\texttt{stock} and cannot pass zero. The bank's lending base is
\[
\sum_{\text{deposited mines}}
  \mathrm{stock}(m)\cdot \mathrm{ref}(\mathrm{material}(m)),
\]
where $\mathrm{ref}$ is a smoothed price from recent sales of undeposited
mines of that material. The bank's own posted ore price is not an input.
If no independent sale of that material sits inside the window, the last
reference is carried forward. The optional revenue floor of Part~III is off
unless a run shows a hoarded mine marking high.

\subsection{The financial chart}

Every financial row sums to zero across holders. Real rows do not.

\begin{center}
\small
\begin{tabular}{@{}llll@{}}
\toprule
Instrument & Asset of & Liability of & Transfer \\
\midrule
Monetary deposit & holder & the issuing bank & \texttt{pay} \\
Bank loan & the bank & the borrower & never \\
Private loan & current holder & the issuer & \texttt{transferPrivate} \\
Bank share & the holder & that bank & the share market \\
Interbank claim & one bank & the other bank & settlement inside \texttt{pay} \\
\bottomrule
\end{tabular}
\end{center}

A bank loan's fields are the collateral id, the remaining principal, the
installment, the months left, and the bank. A private loan's fields are the
issuer, the holder, the same schedule, and the issuer kind
(\texttt{firm} or \texttt{government}). There is no bond type beside that.
There is no equity in a firm. The owner's claim is \texttt{draw}.

A person's liquid assets, in the order the starvation rule sells them, are
the two deposits (larger balance first), bank shares, private loans held,
and undeposited mines. Houses are absent from that list.

A \texttt{pay} debits the payer's largest balance first and credits the
payee at that same bank. That bank's deposit liability is unchanged.
\texttt{World.interbank} moves only when the payee is a bank and the
payer's balance at that bank is short. The engine debits the payer at the
other bank and books the claim. Interest then raises the creditor bank's
equity. Principal repayment retires the loan. Neither step credits a new
customer deposit. The claim pays no interest. It is not a loan the bank
leaf decides. With that row, deposits still sum to zero across holders and
both banks.

The flow rows, each of which sums to zero across payers and payees, are:
wages, staple, luxury food, nightclub, tuition, private cure, rent, ore,
machine purchase, maintenance, tax, bank interest, bank principal, private
installment, profit draw, dividend, and the trade prices of houses, mines,
debt, and shares. Capital-account rows record $\Delta$ of each instrument.
Bank principal repaid destroys a deposit. Bank interest raises that bank's
equity and shrinks customer deposits until the dividend pays them back out.
A private installment, principal and interest both, moves a deposit and does
not destroy one.

wins a different listing.

\subsection{Invariant}

After every effect, for each of the five financial instruments, the signed
sum across all holders is zero. The five are the monetary deposit, the bank
loan, the private loan, the bank share, and the interbank claim. After the last effect of a month, each
person, firm, bank, and the government has a flow column that sums to zero:
inflows minus outflows equal the change in its net financial assets.
A non-zero column is a leak. Real stocks are checked only for their own
laws: house units are positive multiples of ten, mine stock is non-negative,
a deposited mine has no person as owner, a liened id names a live bank loan,
and a dead person holds nothing.

leverage against the distress discount, and the tax rate against the
savings objective. Sweeping a level, with the ratios fixed, rescales a run.

The parcel count has a constraint the old seed line ``2 mines'' does not

discarded.

Machine purchase prices and maintenance prices at each $(c, g)$ are part of
the $t_0$ price vector. The maintenance price is paid each month to
\texttt{Machine.builder}.

\section{The rulings}
\label{sec:decisions}

\subsection{Two banks}

\texttt{BankId} is \texttt{"a"} or \texttt{"b"}. Each bank has its own loan
rate, deposited mines, shares, dividend, equity, and lending ceiling.
A person, a firm, and the government each hold a deposit at each bank.
A new bank loan creates its deposit as a liability of the lending bank.
A payment credits the payee at the bank that was debited.
\texttt{World.interbank} moves only when someone must pay one bank out of a
deposit at the other. The claim pays no interest.

\subsection{General health}

Luxury food is the only addition to the health stock, and it is still capped
by $H_{\max}(\mathrm{happiness})$. Doctors cure diseases. A cure clears the
hard zero for that disease and does not add points. Staple food resets
starvation and does not touch the stock. There is no clinical good and no
free health grant, so health does not trend upward by itself.

\subsection{The incumbent}

\texttt{keepJob} stays in the container while health is pinned. An unhealthy
worker who wants the post keeps it, at the same salary, until the firm fires
them. Firing remains a firm shape in any month.
\texttt{applyJob} is gated by education only. Selection among non-incumbents
is descending health. A low-health applicant, including a hard zero, is
hired when healthier eligible applicants do not fill the slots.

\subsection{Discretionary purchases go last}

Staple food, and on the special day the year's rent, settle before luxury
food, the nightclub, tuition, and private cures. On the special day the rent
step still follows the job step, because applicants are ranked by the salary
just determined. Investment stays after the discretionary step.

\subsection{An opening shortfall folds}

Wages, debt service, tax, and maintenance are paid before any leaf may
borrow. A firm that cannot meet them folds in that phase. It does not issue
debt first and pay second. That is the squeeze the entrepreneur's order
describes. A loan later the same month cannot reach back and undo it.

\subsection{Maintenance is paid to the builder}

Each machine records the tech firm that built it. Each month the holder pays
that firm the contractual maintenance price for the machine's career and
generation. The payment is a flow row, so the books still balance. If the
builder has folded, the charge is zero that month rather than paid to a
stand-in.

\subsection{No time-preference field}

Education choice reads last year's job archive and trains toward the careers
that listed slots. \texttt{Person} does not carry a separate horizon.
The five objectives already make some agents spend now and others accumulate.

\subsection{The scripted leaves}

The containers and the world are fixed. The function inside each scripted
leaf is chosen by the agent that implements it. None of those functions
reads a model of the economy. The slots are:
